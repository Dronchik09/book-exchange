# 📚 BookExchange — Сервіс обміну книгами

Сучасний повнофункціональний веб-додаток для обміну книгами між користувачами.

## 🛠 Стек технологій

- **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS, TanStack Query (`@tanstack/react-query`), Formik, Zustand, Axios.
- **Backend:** Node.js, Express.js, TypeScript, Prisma ORM, PostgreSQL, JWT, bcryptjs, Nodemailer (Ethereal SMTP / Resend), Yup.

---

## ⚡ Швидкий запуск проєкту

### 1. Бекенд (`/backend`)
```bash
cd backend
npm install
npm run dev
```
Сервер запуститься на `http://localhost:5000`. При першому запуску автоматично створюється тестовий адміністратор та стартові книги.

### 2. Фронтенд (`/frontend`)
```bash
cd frontend
npm install
npm run dev
```
Застосунок буде доступний за адресою `http://localhost:3000`.

---

## 👤 Тестові облікові записи

- **Адміністратор:**
  - Email: `admin@book.com`
  - Пароль: `admin123`
  - *Має доступ до `/admin` (керування користувачами) та право видаляти книги будь-кого.*
- **Користувач (User):**
  - Можна зареєструвати на сторінці `/register` (роль `USER` за замовчуванням).
  - Має доступ до `/me/books` (CRUD власних книг) та надсилання запитів на обмін.

---

## 📦 Функціональні можливості

1. **Аутентифікація:** реєстрація, вхід, збереження JWT токена в `localStorage`, захист роутів.
2. **Каталог книг (`/books`):**
   - Пошук за назвою та автором.
   - Сортування за алфавітом (`А → Я`, `Я → А`, `Спочатку нові`).
   - Серверна пагінація.
   - Детальна сторінка книги (`/books/:id`).
3. **Запит на обмін:**
   - Кнопка **«Запросити обмін»** на сторінці книги (недоступна для власних книг).
   - Автоматична відправка листа на email власника книги через `Nodemailer` зі списком книг відправника.
   - Повернення `emailPreviewUrl` (Ethereal) для миттєвого перегляду листа.
4. **Мої книги (`/me/books`):**
   - Додавання книг (назва, автор, фото через URL або локальне завантаження файлу, опис).
   - Редагування та видалення власних книг.
5. **Адмін-панель (`/admin`):**
   - Перегляд усіх користувачів сервісу.
   - Створення користувача з вибором ролі (`USER` / `ADMIN`).
   - Редагування даних або зміна пароля.
   - Видалення акаунтів.
6. **Профіль (`/profile`):**
   - Редагування особистих даних (ім'я, email, аватар).
   - Лічильники доданих книг та отриманих запитів на обмін.
   - Історія отриманих запитів.
